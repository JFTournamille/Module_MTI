# Module MTI

Dépôt du projet Module MTI.

## Organisation des branches

| Branche | Rôle |
| --- | --- |
| `main` | Branche principale — code stable et validé |
| `test` | Branche de développement / recette — intégration et tests avant fusion dans `main` |

Workflow : développer sur `test` (ou une branche dédiée créée depuis `test`),
puis fusionner dans `main` une fois les tests validés.
